# NexForge 升级与使用指南

适用代码版本 Code version：3.0.1  
更新日期 Update date：2026-11-28  
语言 Languages：中文和 English

## 中文

这份指南说明如何使用近期更新的资产库、动作模板、动态缩图和软件连接。已在本地开发目录更新代码的用户，重启工作台后使用。其他用户应安装维护者提供的、包含这轮代码的版本；仅复制这三份说明文档不会更新程序。

### 升级已有工作台

1. 保存正在编辑的设计和专业软件工程，退出旧工作台。
2. 按所获取版本的安装或更新方式替换程序文件。保留现有用户数据，不要为了更新而清空资产来源和模板引用。
3. 重新启动工作台，进入“设置”，检查软件连接。
4. 若原生资产仍使用旧分类，在资产库重新扫描或在动作库刷新。大量文件的第一次索引需要时间，可根据界面进度判断是否完成。
5. 插件更新若提示需要重开，先在 UE 或 Blender 保存工作，再重新打开对应软件。

常规用户数据位于 `%LOCALAPPDATA%/NexForge/Data`，特殊部署可能指定其他目录。不要将个人数据目录作为程序更新包整体覆盖。

### 连接 UE

1. 在 Unreal Editor 中打开需要制作的工程，等待编辑器完成主要加载。
2. 在工作台打开“设置”，找到 UE 的 AIGW 插件连接，点击“安装并连接”。
3. 工作台识别已打开的项目。出现多个目标时，选择要接入的那个项目。
4. 等待“已连接”和工具数量出现。有兼容的官方 MCP Python 接口时可即时启用；否则按照提示保存并重开工程一次。
5. 此后工作台会尝试自动连接。切换工程后，应确认连接指向当前项目，再进行 AI 编辑。

插件安装位置为所选工程的 `Plugins/AIGWBridge`。工程描述需要补齐启用配置时，原文件备份保留在工程的 `Saved/AIGWBridge` 下；旧插件更新时还可能保留 `Saved/AIGWBridge-backup-…` 目录。

普通使用不要求复制插件到引擎全局目录。UE 官方 MCP 和 AIGW Bridge 是不同的连接入口；AIGW 的首次即时启用可以利用兼容的官方接口，但不能假设所有 UE 版本都开放了它。

### 连接 Blender

1. 打开需要使用的 Blender。
2. 在工作台“设置”中点击 Blender 的“安装并连接”。
3. 工作台识别运行版本和安装位置。出现目标选择时，选择正确窗口。
4. 如果提示首次安装需要重开，先保存场景，再退出并重新打开 Blender。
5. 启动加载器会自动启用桥接；工作台检测后自动连接，通常无需再到偏好设置勾选插件。

重开后连接状态可能需要等待一个自动检测周期，也可以点击连接按钮重试。不要反复打开新的 Blender 窗口代替重开原来的目标。

### 配置 AI 助手

1. 在“设置”的 AI 助手区域选择 API 服务或本地模型服务，例如 Ollama、LM Studio。
2. 填写服务地址和实际模型标识；云端服务按需填写 API Key 和真实输入输出价格。本地模型先在对应软件中启动服务。
3. 点击保存，再进行检测。模型是否支持工具调用或识图，以实际能力和检测结果为准。
4. 按需要设置各模块的模型与路由。专业软件连接提供操作通道，AI 模型配置决定由哪个模型执行辅助任务，两者都需要完成。

### 添加资产和下载资源包

1. 打开“资产库”，使用“添加文件”“添加文件夹”，或将文件和文件夹拖入。
2. 等待索引结束，再按图片、视频、音频、模型、UE 资产或动作筛选。
3. UE 文件会优先读取实际类型。需要修正用途分类时，使用人工分类操作。
4. 查看封面、文件名、路径和状态。缺少图片不一定代表文件未识别，也可能是源文件没有内嵌缩图或同名封面。
5. 对 Epic 下载资源，在本机下载资源库区域添加 VaultCache 目录或单个资源包目录，再展开资源包。

资源包需要有可读取的清单和实际文件。只有分块、下载未完成或原始依赖缺失时，先在原下载或编辑器流程中补齐。

### 导入动作模板

| 资源 | 操作 |
| --- | --- |
| FBX、BVH、GLB、glTF 动画文件 | 在动作库选择“直接导入”，选取包含真实动画的文件。静态模型不会作为动作模板导入。 |
| UE 原生动画资产或 .uproject | 在“直接导入”中选择文件，保留其原工程目录结构。 |
| 整个 UE 工程或动作资源包文件夹 | 使用“导入 UE 工程文件夹”，也可在动作画布中拖入对应文件夹。 |
| 已连接工程中的动作 | 使用 UE 资源同步，让真实资产类型补充到动作库。 |
| 下载资源包中的动作 | 展开资源包时接入可识别的原生动作；没有所属工程的包仍需先加入 UE 工程才能生成 UE 预览。 |

在动作模板列表搜索名称或标签，悬停查看动作，拖入动作画布作为引用。需要精确调整、重定向、骨骼或材质编辑时，进入 Blender 或所属 UE 工程完成。

### 动态缩图和滚动

- 在动作卡片上停留鼠标，已有缓存会播放；移开后停止。资产库中的 UE 动画卡片也使用这一流程。
- 第一次生成 UE 动态预览需要所属工程、桥接、预览骨架网格及本机 Blender。首次生成可能有等待，之后复用缓存。
- 混合空间显示代表样本，姿态资产不保证连续播放。没有可用采样接口时，在 UE 动画编辑器中查看。
- 模板列表用滚轮或左侧滚动条上下移动。页面和左侧功能导航也可独立滚动。
- 鼠标位于画布上时，滚轮用于画布缩放；要滚动模板列表，请把鼠标移到模板列表区域。

### 移除和删除

“从库中移除”只移除工作台中的引用，保留磁盘源文件。它适用于暂时不想在库里显示某项资源的情况。

“删除源文件”会影响磁盘资源，应先检查路径与影响，再明确确认。所属 UE 工程已连接时，会检查引用并通过编辑器删除；未连接时只能提示无法检查引用，并按确认结果移入回收站。建议先连接所属工程再删除原生资产，避免破坏其他资产的依赖。

### 常见问题

| 情况 | 建议 |
| --- | --- |
| 安装完成但未连接 | 查看是否提示重开软件；先保存，重开原项目或 Blender，再等待自动检测。 |
| 打开 UE 后还要求选择工程 | 多个项目同时运行时需要选择目标；只打开引擎启动页而未进入项目时，先打开工程。 |
| 能识别文件但没有封面 | 检查内嵌缩图、同目录同名图片与卡片状态；文件类型识别不等于完整内容渲染。 |
| UE 动作已经入库但不能播放 | 确认所属工程、AIGW 连接、预览骨架网格和 Blender；查看是否为静态姿态或不支持的预览类型。 |
| 磁盘资源包只显示清单 | 检查 data 文件是否实际存在、下载是否完成，以及是否只有缓存分块。 |
| 资源很多时暂时没有全部显示 | 等待索引进度结束；可先按具体目录分批添加。模板区采用可见范围绘制，并非所有卡片同时加载。 |
| 连接成功但 AI 助手不能执行 | 检查设置中的 API 或本地模型配置。编辑器连接成功不代表已经配置可用 AI 模型。 |
| 替换了源文件后还是旧预览 | 刷新或重新扫描，等待对应预览缓存失效并重新生成。 |

反馈问题时提供软件版本、目标编辑器版本、文件类型、操作步骤和界面提示。不要公开 API Key、会话令牌或不允许公开的资源。

## English

This guide covers the updated asset library, motion templates, animated previews, and editor connections. Users of the updated local development directory should restart the workstation. Other users need an application build containing this patch; copying these documents alone does not update the program.

### Updating an existing installation

1. Save current designs and editor projects, then exit the old workstation.
2. Replace application files using the supplied installation or update procedure. Retain user data and existing asset and template references.
3. Restart the workstation and check editor connections in Settings.
4. Rescan assets or refresh the motion library if native files still show older classifications. Initial indexing of a large source takes time; check its progress.
5. If a plugin update requires reopening, save the UE project or Blender scene before doing so.

User data normally lives in `%LOCALAPPDATA%/NexForge/Data`, although custom deployments can use another location. Do not overwrite the personal data directory as a whole when updating program files.

### Connecting UE

1. Open the target project in Unreal Editor and allow its main loading to finish.
2. In workstation Settings, choose “Install and connect” for the AIGW UE connection.
3. Select the intended project if multiple targets are listed.
4. Wait for a connected state and tool count. A compatible official MCP Python interface can allow immediate activation; otherwise save and reopen the project once as prompted.
5. The workstation then attempts automatic connection. After switching projects, confirm the target before AI edits.

The plugin is installed in the selected project's `Plugins/AIGWBridge` directory. Descriptor backups are stored under `Saved/AIGWBridge`; plugin upgrades may also retain `Saved/AIGWBridge-backup-…` directories.

Normal use does not require copying the plugin into the engine's global plugin folder. Official UE MCP and AIGW Bridge are separate connection entries. The official interface can help activate AIGW, but is not assumed available in every UE version.

### Connecting Blender

1. Open the Blender version you intend to use.
2. Choose its “Install and connect” button in workstation Settings.
3. Select the correct target when requested.
4. If first installation requires reopening, save the scene, exit, and reopen Blender.
5. The startup loader enables the bridge automatically, and the workstation detects and connects to it.

Connection status can take an automatic detection cycle to update after reopening; the connection button can also retry. Avoid repeatedly opening additional windows instead of reopening the intended target.

### Configuring the AI assistant

1. In the AI assistant area of Settings, choose an API provider or a local service such as Ollama or LM Studio.
2. Enter the service address and actual model ID. Supply an API key and accurate input/output prices when required by a cloud service. Start a local model server in its own application first.
3. Save and run detection. Tool calling and vision depend on the model's actual capabilities and detection results.
4. Select module models and routing as needed. An editor connection provides the operation channel; model configuration selects the AI that assists with the task. Both must be configured.

### Adding assets and downloaded packages

Use Add files, Add folder, or drag and drop in the asset library. Wait for indexing, then filter by media, models, UE assets, or motion. Native UE classification prioritizes actual type metadata; usage categories can be corrected manually.

Inspect the cover, name, path, and status. A missing image may mean the file has neither a readable embedded thumbnail nor a matching nearby cover, rather than a failed file import.

For Epic downloads, add a VaultCache root or a single package in the local download-library area, then expand it. A readable manifest and actual data files are required. Complete partial downloads or chunk-only caches through the original download workflow.

### Importing motion templates

| Resource | Workflow |
| --- | --- |
| FBX, BVH, GLB, or glTF animation | Use Direct import and select a file containing real animation. Static models are not imported as motion templates. |
| Native UE animation or .uproject | Use Direct import and retain the owning project's directory structure. |
| UE project or motion-package folder | Use Import UE project folder, or drop it onto the motion canvas. |
| Motion in a connected project | Synchronize UE resources to supplement the library with actual asset types. |
| Motion in a downloaded package | Expand it to index recognizable motion. Packages without an owning project must first be added to a UE project for native preview generation. |

Search templates by name or tag, hover to preview, and drag them onto the motion canvas as references. Perform precise editing, retargeting, skeletal work, or material editing in Blender or the owning UE project.

### Preview and scrolling controls

- Hover over a motion card to play its cached preview; move away to stop. Native animation cards in the asset library use the same workflow.
- First-time UE generation requires the owning project, bridge, preview skeletal mesh, and local Blender. Generation can take time; later playback reuses the cache.
- Blend spaces show representative samples. Pose assets are not guaranteed continuous playback. Unsupported sampling types should be viewed in the UE animation editor.
- Use the wheel or left scrollbar to scroll templates. The page and left navigation scroll independently.
- The wheel zooms when the pointer is over the canvas. Move it over the template list to scroll that list.

### Removal and deletion

Remove from library removes the workstation reference and retains the source file. Delete source file affects disk content and requires explicit confirmation after checking the target and impact.

A connected owning UE project allows reference checks and editor-side deletion. Without that connection, the confirmation warns that references cannot be checked before moving files to the recycle bin. Connect the owning project before deleting native assets to reduce the risk of breaking dependencies.

### Troubleshooting

| Symptom | Next step |
| --- | --- |
| Installed but not connected | Check for a reopen prompt, save, reopen the intended editor, and wait for detection. |
| UE still asks which project to use | Select among running projects; an engine launcher without an open project is insufficient. |
| Recognized file has no cover | Check embedded or matching nearby images and the card status. Recognition is not full rendering. |
| Imported UE motion will not play | Check its project, bridge, preview mesh, and Blender. It may be static pose data or an unsupported preview type. |
| A disk package exposes only a manifest | Check for actual data files, download completion, and chunk-only storage. |
| A large library is not fully visible yet | Wait for indexing or add narrower folders in batches. Template rendering intentionally uses the visible range. |
| Editors connect but the AI assistant cannot execute | Configure an API or local model. A working editor bridge does not configure an AI provider. |
| Replaced source still shows an old preview | Refresh or rescan and allow the affected cache to regenerate. |

When reporting an issue, include application and editor versions, file type, steps, and visible messages. Do not publish API keys, session tokens, or restricted assets.
