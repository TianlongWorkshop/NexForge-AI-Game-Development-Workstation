## 更新内容

- 改进 UE 原生资源类型识别，区分动作、骨架与动画蓝图等类型。
- 增加原生动作模板索引、悬停动态预览、滚动与大型列表优化。
- 简化 Blender / UE 桥接插件的安装和目标选择流程。
- 修复动作分类、预览播放、重新扫描、多窗口会话和连接栏等问题。

开发阶段最后一轮回归记录为 60 项应用测试和 12 项 Python 桥接测试通过；UE 5.9 与 Blender 4.2.2 做过真实连接和场景读取检查。这些结果不是本次安装包的干净机器安装测试。首次 UE 动作预览需要所属工程、桥接、预览骨架网格及本机 Blender；并非每项资源均有预览。
