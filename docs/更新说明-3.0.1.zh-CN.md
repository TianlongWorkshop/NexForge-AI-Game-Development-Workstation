# NexForge · 连接锻造 3.0.1

NexForge 是一个本地优先的 AI 游戏开发工作站。它把游戏设计、资产管理、动画、材质、Blender 和 Unreal Engine 工作流放进一个可追踪的画布系统。

## 设计思路

NexForge 不把 AI 当成完全自动生成器，而是让人工设计、真实资产、可视化关系和专业软件桥接共同形成可复用生产流程。用户先通过画布表达任务、角色、阵营、地图、对白、物品和生产关系，再由 Agent 在明确范围内读取资料、提出计划、调用 Blender/UE 工具并返回日志与差异。

## 近期功能更新

- 设计总览：整合任务线、场景对白、角色、阵营、关系网、地图、地点/载具/收集品、物品合成、概念图、文档、日历、零部件、动作、材质、UE 行为、Bug 和开发日志。
- 关系网：角色、阵营、地点和关系变化支持结构化属性；角色可填写姓名、主角/配角/NPC、所属阵营、动机和资产引用；阵营可填写名称、徽记、口号、核心属性、盟友和敌对关系。
- 场景对白：场景、说话角色、情绪、台词、镜头、触发条件和事件结果。
- 画布：无限画布、缩放、平移、网格、节点模板、拖线、框选、多选、复制、删除、撤销重做、画布/列表视图。
- 资产库：文件夹扫描、缩略图、来源路径、资产拖入节点和项目引用。
- 动作模板库：FBX、BVH、GLB、glTF 导入、缩略图、动作片段和骨骼检查。
- AI 助手：API 模型、本地 Ollama/LM Studio、模型检测和按模块路由。
- 专业桥接：Blender Bridge 与 UE5.9 AIGW Bridge；真实项目的写入前提是桥接 ready、范围明确并完成人工确认。
- 设计包：`.aigw-design.json` 结构化导入导出，保留模块、节点、连线、资产引用和版本。

## 测试与边界

UE5.9 和 Blender 已完成真实桥接验证；枪械拆解/组装 proof 已完成。没有配置 AI Provider 时，系统不会伪造 Agent 执行。UE 资产和关卡保存仍遵循编辑器安全策略，需要在 UE 中手动保存全部/另存为。

## 安装

运行 `安装NexForge.cmd`。程序安装到 `%LOCALAPPDATA%\\NexForge`，并创建桌面快捷方式。卸载运行 `卸载NexForge.cmd`。
