## 4. 当前发现的功能缺口/限制

### A. 开箱即用缺口（安装包本身不包含）

1. **AI 助手不能直接对话**：默认 `providers=0`，需要用户自行配置 DeepSeek/OpenAI 兼容 API、Ollama 或 LM Studio；安装包不附带 API Key 或本地模型。
2. **Blender / UE5 联动不能直接使用**：安装包不包含 Blender、UE5，也不自动安装 AIGW Bridge 插件；需要用户安装外部软件并绑定路径、装桥接插件。默认三个连接均为 disconnected。
3. **资产库默认是空的**：需要用户添加资产文件夹/导入素材；没有内置示例资产库。
4. **首次没有项目**：需要先点“添加项目”并选择父文件夹；没有内置示例项目或模板工程。

### B. 安装包/发布层缺口

5. **未做数字签名**：`Get-AuthenticodeSignature` 为 `NotSigned`，Windows SmartScreen 可能提示“未知发布者”；下载页已提示用户核对 SHA256。
6. **没有自动更新/更新通道**：用户需要手动下载新安装包覆盖安装。
7. **没有崩溃上报/遥测**：本地优先是优点，但出问题只能让用户导出诊断。
8. **没有安装包内的 EULA/隐私政策**；如对外正式发布，建议补上。

### C. 产品功能层还需要继续验证/补齐

9. 设计总览的默认 19 节点是演示性设计模块，不等于每个模块的完整生产流程都已打通；需要在有项目、有资产、有外部工具的真实环境里逐模块验收。
10. 动作库/UE 行为蓝图/材质蓝图等模块的深度操作本次只验证了页面与空状态，未验证真实资产闭环。

## 5. 结论

安装包已经可以作为“下载后双击安装、像普通软件一样启动”的 Windows 发布包使用；安装与卸载链路、全新首次启动、项目创建、23 个模块入口均通过验证，且安装包内没有混入开发/测试/使用数据。

对外发布前建议至少补两件事：**代码签名证书**（消除 SmartScreen 警告）和**首次启动引导**（提示用户配置模型/绑定 Blender/UE，而不是让 AI 助手和连接状态空着）。
